Restricciones en Windows

Guía rápida para bloquear la instalación de extensiones en Microsoft Edge y bloquear el acceso a Microsoft Store para todos los usuarios del equipo.

🌐 Microsoft Edge Impide instalar cualquier extensión.
🛒 Microsoft Store Bloquea su ejecución mediante AppLocker.
👥 Alcance Configuración pensada para todos los usuarios.

1 Bloquear extensiones en Microsoft Edge

1

Abre PowerShell como administrador

Busca PowerShell, haz clic derecho y selecciona Ejecutar como administrador.

2

Elimina una configuración anterior incorrecta, si existiera

Remove-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Edge" -Name "ExtensionInstallBlocklist" -ErrorAction SilentlyContinue
3

Crea la lista de bloqueo

New-Item -Path "HKLM:\SOFTWARE\Policies\Microsoft\Edge\ExtensionInstallBlocklist" -Force | Out-Null
4

Bloquea todas las extensiones

New-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Edge\ExtensionInstallBlocklist" -Name "1" -PropertyType String -Value "*" -Force

El valor * significa: bloquear todas las extensiones.

5

Comprueba la política

Abre Edge y escribe:

edge://policy

Pulsa Volver a cargar directivas y verifica que aparezca ExtensionInstallBlocklist sin errores.

Resultado: ningún usuario del equipo podrá instalar extensiones en Microsoft Edge.

2 Bloquear Microsoft Store con AppLocker

1

Activa Identidad de aplicación

En PowerShell como administrador ejecuta:

sc.exe config appidsvc start=auto
Start-Service AppIDSvc

Comprueba el estado con:

Get-Service AppIDSvc

Debe aparecer como Running.

2

Abre AppLocker

Presiona Win + R, escribe secpol.msc y ve a:

Directivas de control de aplicaciones → AppLocker → Reglas de aplicaciones empaquetadas

3

Crea las reglas predeterminadas

Clic derecho en Reglas de aplicaciones empaquetadas → Crear reglas predeterminadas.

Esto permite que las demás aplicaciones empaquetadas de Windows sigan funcionando.
4

Crea la regla para Microsoft Store

Clic derecho → Crear nueva regla y configura:

  • Acción: Denegar
  • Usuario o grupo: Todos
  • Referencia: aplicación empaquetada instalada
  • Aplicación: Microsoft Store / Microsoft.WindowsStore
  • Nombre: BLOQUEAR - Microsoft Store
5

Activa la aplicación de las reglas

Clic derecho sobre AppLocker → Propiedades. En Reglas de aplicaciones empaquetadas marca Configuradas y selecciona Aplicar reglas.

No dejes la colección en Solo auditoría, porque en ese modo Store no será bloqueada.
6

Actualiza las políticas y reinicia

gpupdate /force
shutdown /r /t 0
Resultado: Microsoft Store puede seguir mostrando su icono, pero al intentar abrirla AppLocker debe impedir su ejecución.
